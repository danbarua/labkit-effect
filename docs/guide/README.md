# The labkit guide

How to install labkit and use it: what it does, what it asks before it does it, and how to change
that. How labkit is built is described in the design docs (`docs/*.md`), one for each part.

| Page | What it covers |
| --- | --- |
| [Getting started](getting-started.md) | Installing labkit, the `labkit` command, models and keys, sessions. |
| [Trusted folders](trusted-folders.md) | Which of a folder's own files labkit reads, and when. |
| [Permissions](permissions.md) | What labkit runs without asking, what it asks about, and rules that change both. |
| [Logs and telemetry](logs-and-telemetry.md) | Where labkit's logs are, and how to see its traces, logs and metrics in Grafana. |

The editor integration (ACP) is described in the main [README](../../README.md#in-an-editor).
